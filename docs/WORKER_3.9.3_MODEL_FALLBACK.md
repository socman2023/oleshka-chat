# Worker Олешки 3.9.3 — Gemini 404 fallback (04.11.2026)

**Единственная допустимая база:** утверждённый владельцем `oleshka-worker-v3.9.2-friendly-errors.js` (подготовлен из 3.9.1). **Запрещено** использовать 3.8.0 или иные устаревшие Worker.

В 3.9.2 при HTTP 404 выполнялся `retryable:false`, каскад прерывался до резервных моделей. В 3.9.3 исправление одно:

```js
const GEMINI_RETRYABLE_HTTP = new Set([404, 408, 429, 500, 502, 503, 504]);
```

Номер версии в GET `/` изменён с 3.9.2 на 3.9.3, уточнены комментарии. Не затронуты профиль, дневник, хронология, RAG, лимиты, административные функции, UI и Cron. Для HTTP 400/401/403 и SAFETY резервирования нет.

Полный исправленный приватный файл предоставлен владельцу отдельно, **не публикуется в открытом репозитории**. SHA-256 версии 3.9.3: `a592f5db7b0eb808d0d8e096e63a8b1d78c5bfecbd63f9b17b9669c30edb339e`. Текстовая копия исходного 3.9.2 извлечена из Project файлов и не побайтово идентична (222923 байта против 222928 исходных); для отката сохранить прежнее развёртывание Cloudflare.

Проверки: `node --check`, 8/8 Node mock-тестов (404→резерв, 400/401/403 стоп, 429/503→резерв, SAFETY стоп, успех без лишних вызовов, все 404→управляемый отказ).

**GitHub не развёртывает Worker автоматически.** Для установки: Cloudflare → Workers & Pages → `oleshka-chat-api` → Edit code → вставить полный `oleshka-worker-v3.9.3-model-fallback.js` → Deploy. Убедиться, что GET `https://oleshka-chat-api.boysinger2008.workers.dev/` возвращает `"version":"3.9.3"`. `/health` у Олешки не существует. Пока владелец не выполнил Deploy, рабочий Worker не считается обновлённым.
