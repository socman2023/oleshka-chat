## Ошибка и каноническое исправление

В реальной переписке Санко звучало «Живы, слава Богу!». Автор подтвердил общую для обоих героев норму: **Олешка и Санко говорят «Слава Вароку!»**. Выражение реально присутствует в опубликованных книгах **2 и 3** и в дневнике; герои не православные христиане, а язычники со своими пантеонами.

В Worker Олешки 3.9.4:
- Добавлен узкий раздел в `OLESHKA_SYSTEM` о его вере и каноническом «Слава Вароку», без обязательного упоминания богов при каждом ответе.
- Добавлена `normalizeOleshkaFaith`, которая корректирует только собственную незакавыченную стандартную присказку «слава Богу» → «слава Вароку»; дословные цитаты чужих верований не меняются.
- В успешном `POST /api/chat` и в запись D1 `persistChatTurn` используется **одно и то же** скорректированное значение `spokenReply`.
- У идентификатора версии GET `/` указано `3.9.4`.

Остальное **не меняли**: дневник и его синхронизацию, RAG, KV/D1, разговорную историю, лимиты, права, авторизацию VK, админ-панель, Cron и fallback HTTP 404 для Gemini из версии 3.9.3.

Полный приватный JS в публичный GitHub не загружен. Подготовлен отдельный архив для владельца: `Oleshka_Worker_3.9.4_Varok.zip` со всем Worker, diff, инструкцией и тестами.

SHA-256 итогового JS 3.9.4: `5783f8d53d067466fc07e1afeda80403f68233aa783b4881baa22194e6134a7b`.
